# Fuentes oficiales verificadas

Fecha de verificacion: 2026-09-09.

1. Servicios de Urgencias y Ambulancias - Secretaria Distrital de Salud. Recurso CSV 2026. Actualizacion de datos: 23 de julio de 2026. Columnas verificadas: Pestador, Sede, Direccion, Telefono, Email, Grupo de Servicio, BASICO, MEDICALIZADO, URGENCIAS.
2. Llamadas de Urgencias y Emergencias que ingresan a traves de la Linea 123 - Secretaria Distrital de Salud. Recurso CSV julio 2026. Actualizacion de datos: 4 de septiembre de 2026. Columnas verificadas: NUMERO_INCIDENTE, FECHA_INICIO_DESPLAZAMIENTO_MOVIL, CODIGO_LOCALIDAD, LOCALIDAD, EDAD, UNIDAD, GENERO, TIPO_INCIDENTE, PRIORIDAD_FINAL, RECEPCION.
3. Red Semaforica de Bogota D.C. - Secretaria Distrital de Movilidad. Fecha del dato: 12 de junio de 2026; ultima actualizacion del metadato: 2 de septiembre de 2026. Recursos disponibles: ArcGIS, CSV, Shapefile, GeoJSON y KML.
4. Malla Vial Integral Bogota D.C. - IDECA / Datos Abiertos de Movilidad. Dataset oficial de ejes viales de la ciudad; se usa como fuente conceptual para construir la red vial del prototipo y como fuente completa para escalar la Fase 2.

Nota: por limitaciones de ejecucion sin acceso directo a Internet dentro del entorno de generacion, este repositorio incluye un dataset inicial normalizado y reducido para Fase 1. El archivo README deja indicadas las fuentes oficiales para reemplazar la muestra por los CSV/GeoJSON completos.
